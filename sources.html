Learning and media design

The lesson uses short learner-controlled segments, visual signals, conversational narration, and application with feedback. No universal attention-span claim is implied.

Accessibility guidance: W3C accessible audio and video guidance and WCAG 2.2 quick reference.

Use the lesson your way

  • Use the large start button, then Back, Next, or the chapter navigation. You can revisit or skip any activity.
  • Audio starts only after Play. Use Replay, the native volume and mute controls, or the speed selector. Sound & display also provides a narration mute setting.
  • Captions follow the recorded speech. Every chapter has a text alternative, and the full descriptive transcript includes all practice and game explanations.
  • The game provides untimed cards, pause, reduced motion, and optional number-key shortcuts. Shortcuts work only when focus is within the game board and can be turned off.
  • Use Tab and Shift+Tab to move among controls, and Enter or Space to activate them. Use the browser’s zoom and text-size settings as needed.

The design targets WCAG 2.2 AA. It has not been certified as fully conformant. No screen-reader usability study has been completed. If a media file fails, the reading alternative remains available.
